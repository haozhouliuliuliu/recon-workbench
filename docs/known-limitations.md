# 已知限制

> 诚实记录"没做"和"做得不完美"的地方，比假装什么都做了更有价值。本文件随阶段推进持续更新。

## 当前（阶段 1）

1. **只支持「台账 ↔ 对账单」一对一匹配。** 不做多对一（一张对账单拆多张发票）、不做一对多（合并开票）。
2. **匹配规则是启发式。** 先发票号、再「供应商 + 日期 + 金额」，不处理跨月、汇率折算、部分红冲。
3. **金额只支持两位小数。** 三位及以上小数的输入会被量化并给出告警，可能掩盖精度问题。
4. **币种不换算。** 不同币种分别汇总，不做汇率折算。
5. **Excel 导出不做模板套打。** 中文表头与样式是代码生成的，不读取用户自定义母版。
6. **CSV 编码靠启发式探测。** UTF-8 / GBK 之外的编码可能失败，需用户转码。
7. **没有鉴权。** 阶段 1 是纯本地命令行工具，不暴露网络端口。
8. **样例数据规模很小。** 未在十万行级别做过性能验证。

## 刻意不做

- RAG、向量检索、多 Agent、本地大模型
- 真实银行/ERP 对接、真实资金操作、真实发票查验
- 用户权限体系、多租户
