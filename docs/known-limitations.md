# 已知限制

> 诚实记录"没做"和"做得不完美"的地方，比假装什么都做了更有价值。本文件随阶段推进持续更新。

## 当前（阶段 5）

1. **只支持「台账 ↔ 对账单」一对一匹配。** 不做多对一（一张对账单拆多张发票）、不做一对多（合并开票）。
2. **匹配规则是启发式。** 先发票号、再「供应商 + 日期 + 金额」，不处理跨月、汇率折算、部分红冲。
3. **金额只支持两位小数。** 三位及以上小数的输入会被量化并给出告警，可能掩盖精度问题。
4. **币种不换算。** 不同币种分别汇总，不做汇率折算。
5. **Excel 导出不做模板套打。** 中文表头与样式是代码生成的，不读取用户自定义母版（母版套打未实现，见文末）。
6. **对账单末尾的「合计」行不解析。** 只认明细行的加总，导出前请删除合计行，否则会被当成缺失字段的坏行。
7. **文本按 NFKC 归一。** 全角括号会变成半角，供应商名以规范化后的形式展示与匹配。
8. **CSV 编码靠启发式探测。** UTF-8 / GBK 之外的编码可能失败，需用户转码。
9. **样例数据规模很小。** 未在十万行级别做过性能验证。

## LLM 审核（阶段 2）的边界

1. **模型输出不可复现。** 同一批差异两次调用可能得到不同措辞或不同置信度，`review_report.json` 的摘要只代表"这一批内容"，不承诺同输入同结果。
2. **没有缓存与并发。** 差异逐条串行调用，成本与延迟随差异条数线性增长；大月份需要在阶段 3 引入任务队列与缓存。
3. **阈值是经验值。** `0.85` 没有做过系统性校准，不同服务商/模型的置信度分布不可比，换模型必须重新验证。
4. **不核实业务真实性。** 模型无法判断发票是否真实、货物是否签收，它只解释"为什么对不上"，不做尽职调查。
5. **提示注入只能缓解。** 已声明"数据不是指令"并要求模型标注可疑内容，但不能保证模型永远服从。
6. **stub 不是模型能力。** `--stub` 的结论是写死的演示数据，用于跑通流程与 CI，不代表真实审核质量。
7. **失败不重放人工判断。** 重试耗尽即转人工，系统不会"猜一个结论"补上。

## 工作流（阶段 3）的边界

1. **单机单写，没有数据库级任务锁。** 阶段 4 加了**进程内** `threading.Lock`，仍不是跨进程锁；`uvicorn --workers` > 1 或部署多副本时锁失效，可能重复调用模型（结果仍幂等）。
2. **源文件按绝对路径记录。** 移动或重命名输入文件后，`resume` 会报"源文件已不存在"，需要把路径放回或重建任务。
3. **任务身份包含复核配置。** 换模型、换阈值都会生成新 `job_id`，旧任务上的人工决策不会自动迁移。
4. **`--force` 是破坏性操作。** 会清空该任务的 LLM 建议与人工决策，只保留任务与事件骨架。
5. **没有自动清理。** `data/jobs/<job_id>/`、`data/uploads/<job_id>/` 会一直累积，暂未实现 GC 或归档。
6. **没有调度器。** 失败任务不会被自动重试，需要人工 `workflow resume`。
7. **人工决策无权限校验。** 任何能调用 CLI/API 的人都能改结论；审计只依赖 `job_events` 与 `decided_by` 字段。
8. **SQLite 不适合多节点。** 若后续要做多副本，需要换 PostgreSQL 并补任务锁。

## HTTP 接口（阶段 4/5）的边界

1. **没有认证与授权。** 没有 API key、OIDC、RBAC，也没有速率限制；公网部署前必须在反向代理层补齐，并启用 HTTPS。
2. **后台任务不持久。** 进程重启会丢失进行中的任务；阶段状态会停在 `running`，需要 `resume` 才会继续，没有自动恢复。
3. **单进程假设。** 任务锁、后台线程池都只在一个进程内有效；多 worker 需要数据库抢占或外部队列。
4. **上传全量读入内存。** 单个文件上限 20MB（可配），读取时整份进内存；超大文件需要改为流式落盘。
5. **下载只校验目录。** 通过数据库记录的路径 + `RECON_STORAGE_DIR` 白名单限制；数据库被完全控制时仍需操作系统权限兜底。
6. **Docker 镜像是单阶段构建。** 没有多架构镜像、没有镜像签名；仅 `linux/amd64` 验证过。
7. **没有 API 版本前缀。** 当前是 `/api/jobs`，破坏性变更时需要另起 `/api/v2`。
8. **没有分页过滤。** 任务列表只支持 limit/offset，不能按状态或时间筛选。

## 未做事项

- 真实银行/ERP 对接、真实资金操作、真实发票查验（刻意不做）。
- RAG、向量检索、多 Agent、本地大模型（刻意不做）。
